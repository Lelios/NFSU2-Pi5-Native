# Need for Speed Underground 2 – V28 GOLD

## Nativer Raspberry-Pi-5-Port
Spiele NFS Underground 2 auf Ubuntu ARM64 ohne Wine oder Emulator.

## Grafikverbesserungen
- Korrigierte Straßenreflexionen
- Korrekte Scheinwerferprojektion
- Keine quadratischen Grafikfehler auf der Straße

## Voraussetzungen
- Raspberry Pi 5 mit Ubuntu Desktop ARM64
- Internetverbindung und ausreichend Speicherplatz
- Eigene PC-Spieldateien mit kompatibler SPEED2.EXE (Version 1.0)

## Installation
Repository herunterladen:

    git clone -b pi5-native-v28-gold --single-branch https://github.com/Lelios/NFSU2-Pi5-Native.git
    cd NFSU2-Pi5-Native

Installer starten:

    bash install-pi5-v28-gold.sh

Den Anweisungen folgen und den eigenen Spielordner auswählen.
Die native ARM64-Version wird lokal kompiliert.

## Starten
Desktopverknüpfung: Need for Speed Underground 2 V28 GOLD
