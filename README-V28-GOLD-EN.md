# Need for Speed Underground 2 – V28 GOLD

## Native Raspberry Pi 5 Port
Play NFS Underground 2 on Ubuntu ARM64 without Wine or emulation.

## Graphics improvements
- Corrected road reflections
- Corrected headlight projection
- Removed square artifacts on roads

## Requirements
- Raspberry Pi 5 running Ubuntu Desktop ARM64
- Internet connection and sufficient disk space
- Your own PC game files with compatible SPEED2.EXE (version 1.0)

## Installation
Clone the repository:

    git clone -b pi5-native-v28-gold --single-branch https://github.com/Lelios/NFSU2-Pi5-Native.git
    cd NFSU2-Pi5-Native

Run the installer:

    bash install-pi5-v28-gold.sh

Follow the instructions and select your own game directory.
The native ARM64 executable is compiled locally.

## Launch
Desktop shortcut: Need for Speed Underground 2 V28 GOLD
